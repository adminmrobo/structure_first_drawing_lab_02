# F01~F04 · 비교 그림 다시 받기 (편집 방식) — pr1~pr4 각 2장

첫 결과(E01~E04)는 페이지에 '첫 결과'로 그대로 실었습니다. 아래는 **요청과 어긋난 점만 고쳐** 다시 받는 요청문입니다.
새로 그리지 말고 **받은 그림을 첨부해 고칠 점만 바꾸는 편집**으로 요청합니다. 그래야 두 장의 얼굴·자세가 같게 유지됩니다.

순서(대화마다): ① 받은 `*_guided` 그림을 첨부해 **guided 고치기**를 먼저 받습니다. ② 고친 guided 그림을 첨부해 **naive 만들기**로 일부러 틀린 짝을 받습니다.
저장 이름은 같은 이름(`pr1_haru_guided.png` 등)으로 덮어 주세요. 받으면 페이지 설명을 '고친 결과'로 바꿔 반영합니다.

**Genspark에 먼저 붙여 넣기 ↓**
```
첨부한 그림을 편집해 줘. 인물의 얼굴·머리·자세·구도·그림체는 그대로 두고, 아래 영어 요청문에 적힌 것만 바꿔 줘.
글자·숫자·화살표 같은 표시는 넣지 말고, 흰 배경 그대로.
```
